# אתר "לוח משנה לחק"

אתר סטטי. הכל רץ בדפדפן, ואין צורך בשרת.

## פתיחה
פותחים את `index.html` בלחיצה כפולה. האתר עובד גם בלי אינטרנט, אבל אז הגופנים יוחלפו בגופני ברירת מחדל.

## האתר באוויר
- כתובת: https://memdaf.github.io/mishna-luach/
- המאגר: https://github.com/memdaf/mishna-luach (ציבורי, GitHub Pages מענף `main`)
- **עדכון:** מתוך התיקייה `Web`: `git add -A`, ואחר כך `git commit -m "תיאור השינוי"`, ואחר כך `git push`. האתר מתעדכן אחרי דקה-שתיים.
- **חשוב בכל עדכון:** ב-`index.html` מעלים את מספר הגרסה (`?v=2` ← `?v=3`) בכל הקישורים לקבצי css ו-js. אחרת דפדפנים (וגם נטפרי) עלולים להמשיך להשתמש בקבצים ישנים מהזיכרון.
- **מחיקה:** `gh repo delete memdaf/mishna-luach`
- `.gitignore` מונע העלאה של `node_modules`, `tools` ו-`package*.json`.

## להעלאה לאחסון אחר
מעלים לכל אחסון סטטי (GitHub Pages, Netlify, אתר קיים) את התיקיות והקבצים הבאים:
`index.html`, `css/`, `js/`, `lib/`, `data/`.
אין צורך להעלות את `node_modules/`, `tools/` ו-`package*.json`.

## קבצים
| קובץ | תפקיד |
|---|---|
| `js/engine.js` | מנוע הלוח: משבץ את הלוח לתאריכים לפי פרשת השבוע (מקביל ל-`btnLuachIshiClick`) |
| `js/app.js` | הממשק: הטופס, הטבלה, סימוני "נלמד", הדפסה ו-Excel |
| `js/i18n.js` | מילון הטקסטים בעברית ובאנגלית |
| `css/style.css` | העיצוב, כולל עיצוב ההדפסה (A4) |
| `data/luach_data.js` | הנתונים. נוצר מ-`WebHandoff/luach_data.json` |
| `lib/hebcal.min.js` | ‏Hebcal 6.14: לוח עברי, פרשות, חגים ויארצייט (רישיון GPLv2) |
| `js/excel.js` | ייצוא ל-Excel: עיצוב, רשימת בחירה V בעמודות "נלמד" ושורת סיום |
| `lib/exceljs.min.js` | ‏ExcelJS 4.4: כתיבת קובץ xlsx מעוצב (רישיון MIT) |

## פקודות (מתוך התיקייה `Web`)
- `node tools/build-data.js`: בונה מחדש את `data/luach_data.js` אחרי שינוי ב-JSON.
- `node tools/test.js`: בודק את המנוע על השנים תש"פ עד ת"ת, בארץ ישראל ובחוץ לארץ.
- `node tools/test-excel.js`: בונה קובץ Excel לדוגמה (בעברית ובאנגלית), קורא אותו בחזרה ובודק את העיצוב.
- `node tools/test-en.js`: בודק שבגרסה האנגלית לא נשארו אותיות עבריות בלוח.

## אנגלית
- הכפתור English / עברית בראש הדף מחליף שפה. אפשר גם לקשר ישירות: `?lang=en`. האתר זוכר את השפה האחרונה.
- התעתיק אשכנזי, לפי Hebcal: Bereshis, Shabbos, Sukkos. שמות המסכתות באנגלית נמצאים ב-`MASECHET_EN` ב-`engine.js`.
- הלימוד מתורגם בצורה `Berachos 1`, `Maasros 1:1 – 1:5`.
- סימון "נלמד" נשמר לפי הטקסט העברי המקורי, ולכן הוא נשאר גם כשמחליפים שפה.

## כללים שנקבעו
- **הפרשה של כל יום** היא פרשת השבת הקרובה.
- **הלימוד תמיד לפי סדר הפרשיות בארץ ישראל**, כמו בדלפי. בחוץ לארץ משתנים רק שם הפרשה המוצג ("פרשת חו"ל (פרשת א"י)") ועמודת החג.
- **שבת חול המועד סוכות או שמיני עצרת:** לומדים "וזאת הברכה", כמו בדלפי.
- **שבת אחרת שחל בה חג:** אין קריאת פרשה, ולכן אין לימוד באותו שבוע, כמו בדלפי.
- **עמודת החג:** חגים, צומות, ראש חודש ושבתות מיוחדות, בלי ימים ממלכתיים.
- **מחזור שנתי:** מתחיל ביום ראשון של שבוע פרשת בראשית.
- **סימוני "נלמד"** נשמרים בדפדפן של המשתמש.
- **יארצייט של מי שנפטר באדר של שנה פשוטה:** המשתמש בוחר אם בשנה מעוברת היארצייט באדר א' או באדר ב'.
- **הדפסה:** האתר מחלק את הלוח לדפים בעצמו, וממלא כל דף עד הסוף (שבוע יכול להתחלק בין שני דפים). כששבוע ממשיך לדף חדש, שם הפרשה חוזר בראש הדף.
  - בתחתית כל דף: מימין "מוגש ע"י", באמצע סוג הלוח, ומשמאל הסבר הכוכבית.
  - הסבר הכוכבית מופיע רק בדף שיש בו כוכבית.
  - אם משנים את גובה השורות ב-CSS, צריך לעדכן את `ROWS_PER_PAGE` ואת `ROWS_FIRST_PAGE` ב-`app.js`.
